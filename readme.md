Soft-baked stories is a little pastry shop where the owner sells home baked goods and delivers them around. They primarily use social media as the primary source of advertisement and exposure. But in this project, its goal is to elevate its exposure and convenience of the customer.

This will be a dynamic website with vercel being the storefront and it will also have an admin page. That would also mean it'll require a free tier thing to make the admin and user orders from the storefront.

It will have a user inputs wherein it would send orders to the owner's email in a structured manner. These user inputs would include which product they have selected and what quantity, Name, their phone number as well as their address.

Once the user has submitted their order, it will come through as a JSON file or any other convenient way for it to be sent to the admin page and be translated into a nice dashboard of the contents of the order, set progress status, delivery status, completed orders which would reflect into its very own financial dashboard.

It is a fairly simple system. But beautiful. This will primarily be built in a beautiful glassmorphic design.
